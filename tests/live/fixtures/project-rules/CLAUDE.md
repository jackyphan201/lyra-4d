# Project rules: Summer Camp Program office

- All outward-facing text is in Vietnamese, warm but formal ("Quý phụ huynh").
- Program names must be at most 4 words and avoid English words.
- Never promise prices or dates; write "[sẽ cập nhật]" instead.
- Every deliverable ends with a one-line "Người phụ trách: [tên]" placeholder.
